# NexusPortal

**The Door & Interactive Console to the Nova Ecosystem**

NexusPortal is the unified central gateway and terminal interface for the entire Nova ecosystem, with direct integration to **Grok Launcher**.

### Core Components
- Mesh Networking (xMesh / NovaNet / QNET)
- Blockchain (XCoin / QCoin)
- AI Agent Swarms
- **Grok Launcher** (direct integration)
- Hardware Prototypes

Launch the console:
```bash
cd terminal
cargo run
```
